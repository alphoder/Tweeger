================================================================================
THE ONE-LINE PITCH
================================================================================

Drop your website URL or describe your product. The AI research team takes
over — it studies your brand, researches every platform's algorithm, generates
platform-native content backed by real data, and sends you pixel-perfect post
previews to swipe through on your phone. Swipe right to approve, left to
reject, up to discuss changes with the AI. Once approved, posts schedule at
optimal times, publish automatically, and the system learns from results to
get smarter every single week. You review. It handles the rest.

================================================================================
HOW IT WORKS (USER EXPERIENCE)
================================================================================

STEP 1: User provides ONE of the following:
  - A website URL (e.g., https://myrestaurant.com)
  - A product/startup description (plain text)
  - A social media profile link (existing presence)

STEP 2: The Manager Bot takes over:
  a) BRAND EXTRACTION PHASE (Automatic, ~60 seconds)
     - If URL: Scrapes the website using web fetch
       * Extracts: business name, industry, value proposition, services/products,
         pricing, target audience, tone of voice, key claims, contact info,
         existing social links, brand colors, logo, images
       * Analyzes competitor positioning from the website copy
       * Identifies the business's unique selling points
     - If text description: AI parses and structures the same data
     - If social profile: Fetches existing content, analyzes patterns,
       extracts brand voice and positioning

     Output: A complete Brand Profile stored in the database:
     {
       name, industry, subIndustry, description, valueProposition,
       products: [{name, description, price, targetAudience}],
       tone: {primary, secondary, avoidWords[], powerWords[]},
       targetAudiences: [{persona, painPoints[], desires[], platforms[]}],
       competitors: [{name, url, handle}],
       brandKeywords: [], industryKeywords: [],
       uniqueSellingPoints: [],
       contentThemes: [],  // AI-identified themes the brand should own
       languagePreference: "english" | "hinglish" | "hindi" | "regional",
       location: {city, state, country},
       festivals: [],  // auto-populated based on location + industry
     }

  b) PLATFORM RESEARCH PHASE (Automatic, ~2-5 minutes)
     - Manager Bot dispatches research tasks to ALL 4 platform agents simultaneously
     - Each agent researches:
       * Current algorithm state for this specific industry
       * Trending topics relevant to this brand
       * Competitor content analysis on that platform
       * Hashtag clusters with reach/competition data
       * Best-performing content formats for this industry RIGHT NOW
       * Optimal posting times based on the target audience's behavior
       * Content gaps — what competitors aren't covering
     - Manager Bot synthesizes cross-platform intelligence
     - Generates a "Platform Strategy Brief" for each platform

  c) CONTENT STRATEGY GENERATION (Automatic, ~2-3 minutes)
     - Manager Bot creates a multi-platform content strategy:
       * Content pillars (3-5 themes the brand will consistently cover)
       * Content mix per platform (e.g., LinkedIn: 40% thought leadership,
         30% case studies, 20% industry data, 10% behind-the-scenes)
       * Posting frequency per platform (based on research data)
       * Hashtag strategy per platform
       * Visual style guide (what kinds of images to generate)
       * CTA strategy (what actions to drive on each platform)
       * Save-bait vs share-bait vs reply-bait content ratios

  d) CONTENT GENERATION (Automatic, ~5-10 minutes for a full week)
     - Manager Bot dispatches content generation to platform agents
     - Each agent generates posts using:
       * The brand profile as context
       * Fresh platform research as intelligence
       * Platform-specific algorithm optimization:
         - LinkedIn: dwell-time optimized, 800-1000 chars, save-bait CTAs,
           carousel documents when appropriate, easy-to-answer ending questions
         - Twitter/X: reply-chain sparking hooks, no external links in body,
           text-first format, 1-2 hashtags max, bookmark-bait for threads
         - Instagram: DM-share optimized captions, 3-5 keyword-rich hashtags,
           hook within 125 chars, save-bait carousels, Reel scripts with
           1.7-second hooks
         - Facebook: community discussion starters, NO external links,
           Messenger-share optimized, group-style storytelling
       * AI-generated images via Puter.js txt2img for each post
       * AI scoring: predicted engagement score 0-100 with breakdown

  e) SCHEDULING (Automatic)
     - AI determines optimal posting times based on:
       * Platform research agent's timing intelligence
       * Historical performance data (after first week)
       * Current trend velocity (if a trend is peaking, post NOW)
       * Queue conflict avoidance (minimum 2-hour gap per platform)
       * Day-of-week patterns from research data
     - Posts are queued with exact timestamps

  f) PUBLISHING (Automatic)
     - Scheduler publishes posts at designated times
     - Handles retries on failure (3 attempts with exponential backoff)
     - Notifies admin via Telegram on success/failure
     - Records post IDs for metrics tracking

  g) PERFORMANCE TRACKING (Automatic, every 2 hours)
     - Fetches engagement metrics for all published posts
     - Calculates: engagement rate, save rate, share rate, reply depth,
       impression velocity, reach decay curve
     - Flags "best performing" posts automatically
     - Identifies underperforming content with reasons

  h) SELF-LEARNING LOOP (Automatic, daily at 2 AM)
     - Analyzes all performance data from the past 30 days
     - Generates insights:
       * "Carousel posts about [topic] get 3.2x more saves on Instagram"
       * "Posts at 10 AM on LinkedIn get 67% more engagement than 2 PM"
       * "Questions ending tweets get 2.1x more replies"
       * "Hinglish captions on Instagram outperform English by 45%"
     - FEEDS INSIGHTS BACK INTO THE AGENTS' SYSTEM PROMPTS
     - Next content generation cycle is informed by what actually worked
     - Measures insight accuracy: did following this insight improve results?
     - Confidence scoring: insights with proven impact get higher confidence

  i) ALGORITHM CHANGE DETECTION (Automatic, continuous)
     - Monitors engagement velocity shifts across all client accounts
     - Detects when a format's performance deviates by >2 standard deviations
       from the rolling 14-day mean
     - Flags potential algorithm changes
     - Auto-adjusts content strategy (e.g., if carousel reach drops on
       LinkedIn, shift to polls or text posts)
     - Alerts admin via Telegram: "Algorithm shift detected on Instagram.
       Carousel reach dropped 34%. Shifting to Reels-first strategy."

  j) WEEKLY REPORT (Automatic, every Monday 8 AM)
     - AI-generated narrative report:
       * Per-platform performance summary
       * Best and worst performing content with reasons
       * What the AI learned this week
       * What the AI changed in the strategy
       * Recommendations for next week
       * Competitor movement (if any tracked)
       * ROI dashboard: before vs after AI optimization

STEP 3: USER REVIEWS VIA SWIPE REVIEW DECK (The Core Interaction):
  The system NEVER auto-posts without user verification.
  All generated content goes to the Review Deck — a mobile-first,
  swipe-based interface where the user reviews every post before it
  goes live.

  THE REVIEW DECK (`/review`):

  On MOBILE (primary experience):
    - Full-screen card stack, one post per card
    - Each card shows a PIXEL-PERFECT platform preview mock:
      * Twitter: actual tweet card (avatar, name, handle, text, image, icons)
      * LinkedIn: actual LinkedIn post (profile, headline, text, reactions bar)
      * Instagram: actual Instagram post (profile header, image, caption, likes)
      * Facebook: actual Facebook post (profile, text, image, reactions)
    - Below the preview: AI reasoning panel (collapsible)
      * "Why this works: [research-backed explanation]"
      * AI Score: 87/100 with breakdown
      * Target signal: "Optimized for saves" / "Optimized for replies"
      * Scheduled time: "Tuesday 10:00 AM IST (optimal for LinkedIn)"
    - SWIPE GESTURES:
      * SWIPE RIGHT → Approve (green flash, card flies right, goes to scheduler)
      * SWIPE LEFT  → Reject (red flash, card flies left, marked as rejected)
      * SWIPE UP    → Edit/Discuss (card slides up, opens Manager Bot chat)
    - Haptic feedback on each swipe (mobile vibration)
    - Progress indicator: "3 of 7 posts reviewed"
    - Batch action: "Approve All Remaining" button at bottom
    - Undo: shake phone or tap "Undo" toast that appears for 3 seconds

  On DESKTOP (button experience):
    - Same card layout but arranged as a horizontal card carousel
    - Each card shows the same pixel-perfect platform preview
    - THREE BUTTONS below each card:
      * ✓ APPROVE (green button, keyboard shortcut: →)
      * ✗ REJECT (red button, keyboard shortcut: ←)
      * ✎ EDIT/DISCUSS (blue button, keyboard shortcut: ↑)
    - Keyboard navigation: arrow keys to approve/reject/edit,
      spacebar to flip to next card
    - Side panel shows the review queue with thumbnails

  THE EDIT/DISCUSS FLOW (Manager Bot Conversation):
    When user swipes up or clicks Edit, a chat interface opens
    ON THE SAME CARD — the post preview stays visible at the top
    and a conversation thread opens below it:

    - The Manager Bot opens with context:
      "This is a [platform] post targeting [industry] audience.
       I optimized it for [signal]. What would you like to change?"

    - User can type or voice-note their feedback:
      * "Make the hook more punchy"
      * "Add something about our new product launch"
      * "Change the tone — this is too formal"
      * "Can you make a version for Instagram too?"
      * "I don't like the image, generate a different one"

    - Manager Bot processes the feedback:
      1. Understands the change request
      2. Routes to the appropriate platform agent (or generates new image)
      3. Shows the UPDATED post preview in real-time
      4. Shows what changed: "Updated: Rewrote hook, shortened caption,
         regenerated image with warmer tones"
      5. Shows old version vs new version side-by-side (mobile: tap to toggle)

    - User can continue the conversation:
      * "Better, but change 'automation' to 'smart automation'"
      * "Perfect, approve this one"

    - When satisfied, user can:
      * Tap "Approve This Version" → goes to scheduler
      * Continue editing → another round
      * "Reject" → discard entirely

    - The Manager Bot remembers preferences from these conversations
      and feeds them back into the brand profile's tone and style settings.
      Example: if the user consistently says "too formal," the system
      adjusts the tone for future generations.

  REVIEW NOTIFICATIONS (via Telegram):
    When new posts are ready for review, the system sends a Telegram message:
    "📋 5 new posts ready for review across Twitter, LinkedIn, Instagram.
     Tap to review: [link to /review]"

    If posts haven't been reviewed within a configurable window (default: 4 hours):
    "⏰ Reminder: 5 posts still pending review. Optimal posting times are
     approaching. Tap to review: [link]"

    Quick approve via Telegram (for users who can't open the site):
    - Telegram shows a thumbnail preview of each post
    - Inline buttons: ✅ Approve | ❌ Reject | ✏️ Edit
    - Edit opens a Telegram conversation with the Manager Bot
    - This is a FALLBACK, not the primary flow — the web Review Deck
      is always the recommended experience

  AFTER APPROVAL:
    - Approved posts move to the scheduler queue
    - Posts are scheduled at the AI-determined optimal time
    - If the user edited and the scheduled time has passed,
      the system finds the next optimal slot
    - User gets a confirmation: "✅ Post approved. Scheduled for
      Tuesday 10:00 AM IST on LinkedIn."

  AFTER REJECTION:
    - Rejected post is marked as rejected in the drafts table
    - Manager Bot optionally generates a replacement (configurable)
    - User can set: "When I reject, auto-generate a replacement"
    - Replacement goes back to the Review Deck

  REVIEW ANALYTICS (in Settings):
    - Average review time per post
    - Approval rate (what % of AI-generated posts get approved)
    - Most common edit types (helps the AI learn)
    - Time from generation to approval
    - Posts approved via web vs Telegram

================================================================================
FULL AUTOMATION MODES
================================================================================

ALL MODES require user review before posting. The difference is
how much the AI does before the review step.

MODE 1: FULL AUTO-GENERATE (Default — recommended)
  - AI runs complete pipeline: research → strategy → content → images
  - All generated posts land in the Review Deck
  - User swipes through and approves/rejects/edits
  - Approved posts auto-schedule at optimal times and auto-publish
  - User reviews once per day (morning batch, ~2-5 minutes)
  - If user doesn't review within configurable window, Telegram reminder
  - Self-learning runs automatically

MODE 2: SEMI-AUTO (For users who want more control)
  - AI runs research and strategy automatically
  - User triggers content generation manually ("Generate this week's posts")
  - Generated posts land in Review Deck
  - Same swipe review flow
  - Scheduling is manual (user picks times) or AI-suggested

MODE 3: ON-DEMAND (For users who want full control)
  - User creates posts manually in Content Studio
  - AI provides research intelligence and suggestions as they write
  - User can request AI improvements ("Improve this", "Score this")
  - Posts still go through Review Deck before publishing
  - No auto-generation, no auto-scheduling

────────────────────────────────────────────────────────────
TWITTER/X RESEARCH AGENT
────────────────────────────────────────────────────────────

ALGORITHM INTELLIGENCE (baked into every generation):
  - Reply-to-reply weight: +75 (150x a like) — generate conversation-sparking content
  - Bookmarks: 10x like weight — generate reference/save-worthy threads
  - Text posts > Video for engagement rate — default to text-first
  - External links: -30% to -90% reach penalty — NEVER include links in tweet body
  - Premium subscribers: ~10x reach — recommend Premium to clients
  - Hashtags: max 1-2 per tweet, >2 causes -17% engagement drop
  - Optimal frequency: 3-5 tweets/day, steep drop after 7+
  - Thread sweet spot: 3-5 tweets with visual breaks every 3-4

RESEARCH METHODS:
  - researchTrends(industry, brandProfile)
    → Returns: scored trends with velocity, peak prediction, suggested angles
    → Source: Twitter API getTrends() or AI prediction if free tier
  - analyzeHashtags(topic, industry)
    → Returns: hashtag clusters with volume, velocity, competition
  - analyzeFormats(industry)
    → Returns: current format performance ranking with algorithm boost signals
  - monitorCompetitors(handles[])
    → Returns: content gaps, engagement patterns, topic coverage
  - analyzeAudience(brandProfile)
    → Returns: active hours, engagement patterns (replies vs likes vs RTs)

CONTENT GENERATION METHODS:
  - generatePost(context, research, brandProfile)
    → System prompt includes: brand context + all research data + algorithm weights
    → Output JSON: {
        tweet (max 260 chars),
        hashtags (max 2),
        imagePrompt (for Puter.js generation),
        engagementPrediction (0-100),
        primarySignalTarget ("replies" | "bookmarks" | "retweets"),
        reasoning (why this content + format + timing),
        suggestedReplyStrategy (how to engage when replies come in)
      }
  - generateThread(topic, research, brandProfile, tweetCount?)
    → Multi-tweet thread with hook → value → CTA structure
    → Each tweet designed to pull reader to next (slippery slope)
    → Bookmark-bait formatting: lists, frameworks, reference material
  - generateImage(postText, research, brandProfile)
    → Twitter-optimized 1200x675 image via Puter.js txt2img
  - generateReplyStrategy(tweetId, incomingReply)
    → Suggests reply text to maximize reply-to-reply signal
    → Priority: replies within first 30 minutes

ENGAGEMENT COACHING (unique feature):
  - When a tweet gets replies, the agent generates suggested responses
  - Sends via Telegram: "Your tweet got 5 replies. Here are suggested
    responses to maximize algorithmic reach (reply-to-reply = 75x weight):"
  - Tracks which replied tweets got the most secondary engagement

INSTAGRAM RESEARCH AGENT
────────────────────────────────────────────────────────────

ALGORITHM INTELLIGENCE (baked into every generation):
  - 4 separate algorithms: Feed, Stories, Reels, Explore — each ranked differently
  - DM shares: 50% more weight than any other action — optimize for sendability
  - Saves: 3-5x stronger than likes, 40-60% reach boost — save-bait everything
  - Reels: 1.7-second hook or 50% drop off, 60%+ 3-second hold = 5-10x reach
  - Hashtags: max 3-5 per post (limit dropped from 30), keyword captions > hashtags
  - Caption truncation at 125 chars — hook MUST fit in 125 chars
  - Carousels: 10% avg engagement vs 6% for Reels — highest format
  - Collab posts: 2x+ impressions — suggest collabs when relevant
  - Business accounts miss trending audio on Reels — flag this to users
  - Posts with >2% save rate continue reaching new viewers for 30-60 days
  - High-save content boosts NEXT post's initial reach by 15-25%

RESEARCH METHODS:
  - researchTrends(industry, brandProfile)
    → Visual trends, Reel formats, aesthetic shifts, trending audio
  - suggestHashtags(topic, count=5)
    → Three-tier: 2 broad reach + 2 mid discovery + 1 niche conversion
    → Banned/shadowbanned hashtag detection
  - analyzeCarouselFormats(industry)
    → Top-performing slide counts, CTA placement, save-bait techniques
  - analyzeReelPatterns(industry)
    → Hook styles, pacing, text overlay effectiveness, audio trends
  - monitorCompetitors(handles[])
    → Visual strategy, format mix, hashtag overlap, content gaps
  - analyzeAudience(brandProfile)
    → Save-to-like ratio, Explore discovery patterns, DM share triggers

CONTENT GENERATION METHODS:
  - generateCaption(context, research, brandProfile)
    → Output JSON: {
        caption (visual-first, line breaks, keyword-rich),
        hashtags (3-5, from research),
        imagePrompt (1080x1080 aesthetic),
        engagementPrediction (0-100),
        primarySignalTarget ("saves" | "shares" | "comments"),
        saveHook (what makes this saveable),
        shareHook (what makes someone DM this to a friend),
        reasoning
      }
  - generateCarouselPlan(topic, research, brandProfile, slides?)
    → Slide-by-slide: title, text (100-150 chars), image prompt per slide
    → Hook slide → Value slides → CTA slide structure
    → Optimized for swipe-through dwell time
  - generateReelScript(topic, research, brandProfile)
    → Hook (first 1.7 seconds), body, CTA
    → Text overlay suggestions
    → Audio recommendation (trending if Creator account)
    → Optimal length recommendation (15s/30s/60s/90s)
  - generateImage(caption, research, brandProfile)
    → Instagram-aesthetic 1080x1080 via Puter.js txt2img
    → Style informed by current visual trends from research

LINKEDIN RESEARCH AGENT
────────────────────────────────────────────────────────────

ALGORITHM INTELLIGENCE (baked into every generation):
  - Three-stage pipeline: AI classification → 5-10% network test → extended distribution
  - Dwell time: 3x weight of likes — write for reading, not scrolling
  - Saves: 1 save = 5x reach of 1 like, 2x of 1 meaningful comment
  - DM trigger: if someone messages you, 90% more likely to see your next post
  - Expert comments: 5x more algorithmic weight than random connections
  - Golden hour: first 60-90 minutes determine total reach
  - Author reply within 30 min: +64% total comments, +2.3x views
  - Content lifespan: 2-3 weeks for posts generating meaningful conversations
  - Polls: 1.64x reach multiplier — best performing format
  - Carousels: 1.45x multiplier, 24.42% avg engagement vs 6.67% text
  - Optimal carousel: 8-10 slides, 1080x1080, 100-150 chars/slide
  - Text-only: 0.88x multiplier — weakest standalone format
  - Newsletters: bypass algorithm, 35-40% open rates, 4.48-5.76% engagement
  - Hashtags: 3-5 at end of post, SEO keywords only (following removed)
  - External links: -25-35% reach, mitigate by adding link after 1-2 hours
  - Optimal post length: 800-1000 chars (1300-1600 for top performers)
  - >2000 chars: -35% engagement drop
  - Engagement pods: 97% detection accuracy, 60-90 day recovery penalty
  - Posts ending with easy-to-answer question: +72% better performance

RESEARCH METHODS:
